## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser. No Node.js, no Python, no installation required.

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/panchaldhairya16/Password-Lab-Analyzer-Generator.git

# 2. Navigate into the project
cd Password-Lab-Analyzer-Generator

# 3. Open in your browser
open index.html
# or just double-click index.html in your file explorer
```


## 🧠 How It Works

### 🔍 Analyzer
The analyzer evaluates your password against multiple security criteria:
- **Length check** — minimum recommended character counts
- **Complexity scoring** — uppercase, lowercase, numbers, special characters
- **Common pattern detection** — flags dictionary words, keyboard walks, and repeated sequences
- **Strength meter** — visual indicator from Weak → Fair → Strong → Very Strong

### ⚡ Generator
Generate passwords tailored to your needs:
- Choose length (8–128 characters)
- Toggle character sets: uppercase, lowercase, digits, symbols
- One-click copy to clipboard
- Instant strength preview before you use it

### 📋 Logs
- Keeps a session-based history of generated/analyzed passwords
- Review patterns and audit your choices
- Clear logs anytime with one click
